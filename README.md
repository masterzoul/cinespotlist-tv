# CineSpotList TV

Android TV shell for https://cinespotlist3.pages.dev/

- Designed for Sony / Google TV
- Portrait-style centered content column on a landscape TV screen
- Larger TV-readable typography and posters
- D-pad navigation + OK/Enter
- Full-screen immersive mode
- Web updates automatically appear in the TV app without rebuilding the APK
- API keys remain server-side on Cloudflare; none are embedded in this app

## Build without coding
GitHub Actions builds `CineSpotList-TV.apk` automatically. Download it from the Actions run artifact named `CineSpotList-TV-APK`.
